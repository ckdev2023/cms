### 4. 必须补测试与验证

至少完成：

- 迁移或 schema 校验
- 基础登录相关测试

请总结：

- 新增 / 修改了哪些表或迁移

- 做了哪些登录与鉴权能力
- 跑了哪些测试与验证
- 还缺哪些数据库或权限能力
