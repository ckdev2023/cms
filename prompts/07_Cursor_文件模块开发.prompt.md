## 四、请按以下顺序工作

### 1. 先输出模块理解

请先说明：

- 文件模块在整个系统中的作用
- 本轮明确做什么
- 本轮明确不做什么
- 依赖哪些公共能力（登录、权限、对象关联、存储配置等）

### 2. 输出实施计划

请拆成子任务，例如：

- 数据结构与存储策略
- 上传链路
- 下载链路
- 预览链路
- 元数据编辑与对象关联
- 权限与日志
- 测试与验证

每个子任务写：

- 目标
- 涉及文件
- 风险点
- 完成标准

### 3. 再开始实现

实现时请遵守：

- 先完成最小闭环，不要过早做高级功能
- 类型、大小、归属对象、上传人、时间要记录完整
- 下载要鉴权，关键访问要记日志
- 预览优先图片和 PDF
- DOCX / Excel 不做复杂在线编辑

### 4. 必须补测试

至少完成：

- 上传接口测试
- 下载权限测试
- 元数据或对象关联测试
- 前端上传 / 预览关键交互测试
- 一轮最小 smoke check

### 5. 最终输出

请总结：

- 本轮完成的文件能力
- 修改文件列表
- 测试与验证结果
- 遗留问题
- 下一轮建议（例如：导出、模板生成、版本管理）
