# 事务所管理系统开发文档目录

## 1. 文档说明

本目录用于汇总事务所管理系统的开发阶段核心文档。

本项目定位为：

- 公司内部使用的业务管理后台
- 用户量不大
- 体量不大
- 以提高员工日常工作效率为核心目标

因此整套文档以 **轻量、实用、快速上线、便于维护** 为原则，不做过度架构设计。

## 4. 研发落地建议

建议按以下顺序推进：

1. 先确定一期只做哪些高频功能
2. 再确定技术栈和部署方式
3. 明确核心表结构和页面清单
4. 先开发客户、业务、财务、文件几个主模块
5. 最后补日志、导出、基础安全和上线准备

## 5. 当前建议的架构方向

- 产品形态：内部 Web 管理后台
- 前端：Vue 3 + TypeScript + Element Plus
- 后端：NestJS / Node.js 优先
- 数据库：PostgreSQL
- 文件：NAS 或本地文件目录 + 元数据管理
- 安全：基础账号权限 + 操作日志 + 数据备份
