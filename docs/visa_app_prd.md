# 签证服务客户端 App 产品需求文档（PRD）

## 一、项目背景

本项目为一家提供签证、房产、贷款及二手车服务的公司开发客户端应用，旨在提升客户体验、减少人工沟通成本，并实现业务延展与转化。

## 二、产品目标

1.  客户可实时查看签证进度
2.  客户可在线提交材料与补件
3.  客户可完成账单支付
4.  提供企业客户多人员签证管理能力
5.  提供房产、贷款、二手车等业务入口

------------------------------------------------------------------------

## 三、用户角色

### 1. 个人客户

-   查看个人签证进度
-   上传材料
-   支付费用

### 2. 企业客户管理员

-   查看公司所有员工签证状态
-   管理成员
-   查看企业账单

## 五、状态体系（简化版）

  状态     说明
  -------- --------------
  未开始   尚未开始办理
  待提交   待提交材料
  审核中   材料审核中
  需补件   需补充材料
  已递交   已提交入管局
  审理中   官方审核中
  已批准   审核通过
  未通过   审核失败
  已完成   流程完成

------------------------------------------------------------------------

## 六、设计原则

-   首页优先展示签证状态
-   待办事项突出
-   操作路径清晰
-   风格简洁专业（类似金融类App）

------------------------------------------------------------------------
