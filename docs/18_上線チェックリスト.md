## 5. 品質門禁（デプロイ前検証）

> デプロイ前に必ず実施する品質検証。`deploy.sh` はデフォルトで `ai-deliver.sh --standard` を自動実行するが、手動確認・障害切り分け用に個別コマンドも記載する。

### コマンド体系

| レベル | コマンド | 内容 | 用途 |
|--------|---------|------|------|
| fast | `npm run verify:fast` | lint + 型検査 + JSDoc 品質 | 日常開発の自己検査 |
| standard | `npm run verify` | fast + テスト（前後端） | 機能完成時・リリース前 |
| full | `npm run verify:full` | standard + ビルド（前後端） | 本番デプロイ前 |

> 構造化出力が必要な場合は `bash scripts/ai-deliver.sh --fast|--standard|--full` を使用。内部は同一チェック。

### 個別チェック項目

| # | チェック項目 | コマンド | 完了 |
|---|-------------|---------|------|
| 5.1 | フロントエンド ESLint 合格 | `npm run lint:frontend` | ☐ |
| 5.2 | バックエンド ESLint 合格 | `npm run lint:backend` | ☐ |
| 5.3 | フロントエンド型検査合格 | `npm run type-check:frontend` | ☐ |
| 5.4 | バックエンド型検査合格 | `npm run type-check:backend` | ☐ |
| 5.5 | JSDoc 品質検査合格 | `npm run jsdoc:check` | ☐ |
| 5.6 | フロントエンドテスト合格 | `npm run test:frontend`（vitest） | ☐ |
| 5.7 | バックエンドテスト合格 | `npm run test:backend`（jest） | ☐ |
| 5.8 | フロントエンドビルド成功 | `npm run build:frontend` | ☐ |
| 5.9 | バックエンドビルド成功 | `npm run build:backend` | ☐ |
| 5.10 | 一括検証合格 | `npm run verify:full`（上記 5.1–5.9 を一括実行） | ☐ |

> **最低要求**: リリース前は `npm run verify:full`（5.10）を通過すること。個別項目（5.1–5.9）は失敗時の原因切り分け用。
