# 客户中心在留期限提醒与家族成员简化需求

> 版本：v1.0  
> 适用范围：客户中心（员工建客户流程）  
> 目标：在不引入复杂家族体系的前提下，支持家族成员信息维护与签证 90 天到期提醒。

---

## 1. 背景与目标

当前客户中心已具备客户基础建档能力。为满足行政书士事务场景，需在「新建客户」时补充家族成员与签证相关信息，并提供统一的在留期限提醒能力。

本需求坚持以下原则：

- 不新增复杂的客户门户登录体系。
- 不做外部系统链接集成。
- 先实现可落地、可运营的最小闭环（录入 -> 计算 -> 提醒 -> 跟进）。

---

## 2. 业务范围

### 2.1 本期包含

- 员工在客户中心新建/编辑客户时，维护家族成员基础信息。
- 维护签证到期日。
- 按「90 天内到期」统一规则生成提醒列表。
- 在列表与详情页显示提醒等级。

### 2.2 本期不包含

- 客户自助登录/家族成员独立门户。
- 提醒渠道扩展（短信、邮件推送等）。
- 复杂的家族继承策略与多层家庭关系树。

---

## 3. 字段与口径

以下为本期最小字段（建议）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `isFamilyMember` | boolean | 否 | 是否家族成员 |
| `familyRelation` | string \| null | 条件必填 | 当 `isFamilyMember=true` 时必填（配偶/子女/父母/其他） |
| `primaryCustomerId` | uuid \| null | 否 | 主客户ID，家族成员可选关联 |
| `visaExpireDate` | date \| null | 否 | 签证到期日 |
| `remindDaysBefore` | int \| null | 否 | 预留字段，本期统一按 90 天规则运行 |

说明：

- 本期提醒计算采用统一规则「90 天内」；`remindDaysBefore` 可先保存，后续版本可启用个性化提醒。
- `visaExpireDate` 为空时，不进入到期提醒列表。

---

## 4. 在留期限提醒规则（冻结口径）

### 4.1 计算方式

- `daysLeft = visaExpireDate - today`（按自然日）

### 4.2 提醒范围

- 当 `daysLeft <= 90` 时进入提醒列表。

### 4.3 等级划分

| 条件 | 等级 | 展示建议 |
| --- | --- | --- |
| `daysLeft < 0` | 已过期 | 红色 |
| `0 <= daysLeft <= 7` | 紧急（7天内） | 红色 |
| `8 <= daysLeft <= 30` | 高优先 | 橙色 |
| `31 <= daysLeft <= 90` | 普通 | 黄色 |

### 4.4 排序与筛选

- 默认排序：`visaExpireDate ASC`（越早到期越靠前）
- 默认筛选：`90天内到期 + 已过期`
- 空值处理：`visaExpireDate` 为空不出现在提醒列表

---

## 5. 前端展示与交互要求

### 5.1 新建/编辑客户表单

- 新增「家族成员信息」区块：
  - 是否家族成员
  - 家族关系
  - 主客户（可选）
- 新增「签证信息」区块：
  - 签证到期日
  - 提前提醒天数（可录入，当前规则统一按90天）

### 5.2 提醒列表页

建议字段：

- 客户名
- 家族关系（无则 `-`）
- 签证到期日
- 剩余天数
- 提醒等级
- 操作（查看详情）

### 5.3 客户详情页

展示以下信息：

- 签证到期日
- 剩余天数
- 提醒等级标签

---

## 6. 后端查询与返回口径

### 6.1 查询条件（建议）

- `visaExpireDate IS NOT NULL`
- `visaExpireDate <= today + interval '90 days'`

### 6.2 返回字段（建议）

- `customerId`
- `customerName`
- `familyRelation`（可空）
- `visaExpireDate`
- `daysLeft`
- `alertLevel`（`EXPIRED | URGENT | HIGH | NORMAL`）

---

## 7. 验收标准

- 第 91 天不应出现在提醒列表，第 90 天应出现。
- 当天到期应归类为「紧急（7天内）」。
- 昨天到期应归类为「已过期」。
- 同一客户在列表页与详情页展示的等级一致。
- 无签证日期客户不进入提醒列表。

---

## 8. 测试用例清单（建议10条）

1. `daysLeft=120`，不在提醒列表。
2. `daysLeft=91`，不在提醒列表。
3. `daysLeft=90`，在提醒列表，等级为普通。
4. `daysLeft=31`，等级为普通。
5. `daysLeft=30`，等级为高优先。
6. `daysLeft=8`，等级为高优先。
7. `daysLeft=7`，等级为紧急。
8. `daysLeft=0`，等级为紧急。
9. `daysLeft=-1`，等级为已过期。
10. `visaExpireDate=NULL`，不在提醒列表。

---

## 9. 实施建议（最小改动优先）

- 先完成字段录入与列表提醒，不引入通知推送。
- 先以客户中心内部使用为目标，后续再考虑客户门户化能力。
- `remindDaysBefore` 本期仅保存，避免提前引入多套提醒策略导致复杂化。
